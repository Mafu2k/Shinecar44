# Shinecar44

Strona wizytówka studia detailingu samochodowego **Shinecar44**.
Statyczny serwis prezentujący ofertę, galerię realizacji i kontakt.

🔗 https://shinecar44.pl

## Technologie

- HTML5, CSS3, JavaScript
- Bootstrap
- Font Awesome

## Uruchomienie lokalne

Otwórz `index.html` w przeglądarce lub uruchom prosty serwer statyczny:

```bash
python -m http.server 8000
```
